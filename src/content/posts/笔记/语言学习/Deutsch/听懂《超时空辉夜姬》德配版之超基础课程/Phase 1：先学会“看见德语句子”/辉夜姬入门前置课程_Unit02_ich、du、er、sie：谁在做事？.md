# Unit 02｜ich、du、er、sie：谁在做事？

## 01. 本单元目标

完成本单元后，你应该能够：

- 一眼认出最常见的人称代词；
- 看到 `bin / bist / ist / sind / seid` 时知道它们属于 `sein`；
- 看到 `hab / habe / hast / hat / haben / habt` 时知道它们属于 `haben`；
- 在简单 V1 句子里迅速回答：**谁？做什么/是什么状态？**

## 03. 最小必要规则

### 3.1 先认识“谁”

| 德语 | 先记成 |
|---|---|
| `ich` | 我 |
| `du` | 你 |
| `er` | 他 |
| `sie` | 她 |
| `es` | 它 / 这件事 |
| `wir` | 我们 |
| `ihr` | 你们 |
| `sie` | 他们 / 她们 |
| `Sie` | 您 / 您们 |

> [!important] `sie` 有多个身份
> `sie` 可以是：
> - 她；
> - 他们/她们。
>
> `Sie` 大写时还可以是礼貌的“您”。
>
> 影视字幕里如果它刚好出现在句首，本来就要大写，所以不能只靠大小写判断，要看动词和语境。

---

### 3.2 `sein`：是 / 处于某状态

最先记这一组：

```text
ich bin
du bist
er / sie / es ist
wir sind
ihr seid
sie / Sie sind
```

你不需要现在背“系动词”这个术语。

看到：

`Du bist so schwer.`

先直接拆：

`Du | bist | so schwer`

= 你 | 是/处于 | 这么重

---

### 3.3 `haben`：有

先记：

```text
ich habe / hab
du hast
er / sie / es hat
wir haben
ihr habt
sie / Sie haben
```

影视对白中：

`ich habe` → `ich hab`

非常常见。

这不是“错误德语”，而是自然口语里常见的省音/缩略形式。

---

### 3.4 普通动词先只看“尾巴”

你之后会系统学更多动词。

现在只建立一个识别感：

```text
ich      常见 -e
du       常见 -st
er/sie   常见 -t
wir      常见 -en
ihr      常见 -t
sie/Sie  常见 -en
```

例如：

`ich komme`
`du kommst`
`sie kommt`
`wir kommen`

这只是**识别模板**，不是说所有动词都永远毫无变化。

---

## 04. 结构模型

先把最简单的德语句子看成：

```text
谁 + 变位动词 + 其他信息
```

例如：

```text
Ich + bin + ihr Fan.
Du + bist + so schwer.
Wir + haben + keine Chance.
```

你每次看到一句短字幕，先问两个问题：

1. **谁？**
2. **哪个词是跟着“谁”变化的动词？**

---

## 05. V1 原句精讲

### 句 1

**Ich bin ihr Fan.**
我是她的粉丝。

骨架：

`Ich + bin + ihr Fan`

当前重点：

- `ich` = 我；
- `bin` = `sein` 对应 `ich` 的形式。

不要把 `bin` 当成一个完全独立的新单词去背。

直接背块：

`ich bin`

---

### 句 2

**Du bist so schwer…**
你怎么这么重……

骨架：

`Du + bist + so schwer`

重点：

`du bist`

以后看到 `bist`，基本可以强烈预期附近会有 `du`。

---

### 句 3

**Das ist Yachiyo Runami, eine KI-Streamerin.**
她是八千代月见，一名 AI 主播。

骨架：

`Das + ist + Yachiyo Runami`

这里 `das` 不是人称代词表里的重点，但这句话极其常用：

`Das ist ...`

= 这是…… / 那是……

整块记。

---

### 句 4

**Sie ist eine Cousine!**
她是我的表亲！

骨架：

`Sie + ist + eine Cousine`

重点：

`sie ist`

这里根据剧情语境是“她”。

---

### 句 5

**Ich hab Hunger.**
我饿了。

字面结构：

`Ich + hab + Hunger`

更完整：

`Ich habe Hunger.`

影视口语：

`Ich hab Hunger.`

整块意义：

> 我饿了。

不要硬翻成“我拥有饥饿”。

---

### 句 6

**Du hast uns versprochen, dass wir hingehen.**
你答应过要和我们一起去的。

这句后半还没学，暂时不要碰。

只切第一块：

`Du + hast + uns versprochen ...`

当前只认：

`du hast`

---

### 句 7

**Wir haben keine Chance.**
我们没有胜算。

骨架：

`Wir + haben + keine Chance`

重点：

`wir haben`

`keine` 的否定到 Unit 05 再正式处理。

---

### 句 8

**Ihr habt euch ja Zeit gelassen.**
你们可真够慢的。

骨架先抓：

`Ihr + habt + ...`

现在只需要认：

- `ihr` = 你们；
- `habt` = `haben` 对应 `ihr`。

剩余部分以后再拆。

---

## 06. 高频词与语块

优先整块记：

| 语块 | 意义 |
|---|---|
| `ich bin` | 我是 / 我处于 |
| `du bist` | 你是 / 你处于 |
| `er ist` | 他是 |
| `sie ist` | 她是 |
| `das ist` | 这是 / 那是 |
| `wir sind` | 我们是 |
| `ihr seid` | 你们是 |
| `ich hab` | 我有 / 我…… |
| `du hast` | 你有 / 你…… |
| `sie hat` | 她有 / 她…… |
| `wir haben` | 我们有 |
| `ihr habt` | 你们有 |
| `Ich hab Hunger.` | 我饿了 |
| `Ich bin ihr Fan.` | 我是她的粉丝 |

## 07. 拆句训练

只标两样：

**S = 谁（主语）**
**V = 变位动词**

### 1

`Ich bin ihr Fan.`

### 2

`Du bist so schwer.`

### 3

`Sie ist eine Cousine.`

### 4

`Wir haben keine Chance.`

### 5

`Ihr habt euch ja Zeit gelassen.`

> [!answer]- 答案
> 1. S=`Ich`；V=`bin`
> 2. S=`Du`；V=`bist`
> 3. S=`Sie`；V=`ist`
> 4. S=`Wir`；V=`haben`
> 5. S=`Ihr`；V=`habt`

## 09. 微型输出

只换主语。

### 模板 A

`Ich bin müde.`

换成：

- `Du bist müde.`
- `Sie ist müde.`

### 模板 B

`Ich hab Hunger.`

换成：

- `Du hast Hunger.`
- `Wir haben Hunger.`

### 模板 C

`Ich bin ihr Fan.`

把 `ich` 换成 `wir`：

`Wir sind ihr Fan.`

从纯语法练习角度先观察 `bin → sind` 即可；自然表达中复数时名词部分还可能跟着语境调整，本课不展开。

## 10. 单元自测

### 1

`bist` 最强烈地提示哪个主语？

### 2

填空：

`Ich ___ ihr Fan.`

### 3

填空：

`Du ___ so schwer.`

### 4

填空：

`Wir ___ keine Chance.`

### 5

`Ich hab Hunger.` 中的 `hab` 来自哪个动词？

### 6

找 S 和 V：

`Sie ist eine Cousine.`

### 7

找 S 和 V：

`Ihr habt euch ja Zeit gelassen.`

### 8

`sie` 是否永远只能表示“她”？

> [!answer]- 答案
> 1. `du`
> 2. `bin`
> 3. `bist`
> 4. `haben`
> 5. `haben`
> 6. S=`Sie`，V=`ist`
> 7. S=`Ihr`，V=`habt`
> 8. 不是。还可能表示“他们/她们”；`Sie` 还可作礼貌“您”。

## 11. 通关标准

随机看到 8 个简单 V1 句子时：

- [ ] 至少 6 个能迅速指出“谁”；
- [ ] `bin / bist / ist / sind / seid` 能认成同一家族；
- [ ] `hab / hast / hat / haben / habt` 能认成同一家族；
- [ ] 听 `Ich bin / Du bist / Wir haben` 时不需要逐字翻译。
